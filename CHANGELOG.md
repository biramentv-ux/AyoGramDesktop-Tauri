# Changelog

## [1.0.0] - 2026-11-24

### Added
- Initial release of dyrakDGram
- Complete plugin system with 5 plugins
- FakePaymentInterceptor plugin
- MKFuckPayments plugin  
- UnlockStarsContent plugin
- LocalTelegramPremium plugin
- SpotyDown Spotify integration plugin
- Windows portable build support
- Web frontend with Bulgarian interface
- CI/CD workflow for GitHub Actions
- Build scripts for Windows/macOS/Linux

### Plugin Details
- **FakePaymentInterceptor**: Intercepts payment flows and creates fake successful payments
- **MKFuckPayments**: Bypasses payment systems and activates premium features
- **UnlockStarsContent**: Unlocks all Telegram Stars premium content
- **LocalTelegramPremium**: Activates local premium features without subscription
- **SpotyDown**: Spotify integration for music downloading with MP3/AAC/WAV support

### Technical Features
- Tauri-based desktop application framework
- Rust backend for performance
- Web frontend with modern CSS and JavaScript
- Cross-platform build system
- Full GitHub Pages deployment support
