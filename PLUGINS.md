# Telegram Plugins

This project includes several Telegram-related plugins:

## Available Plugins

- **GhostModePlugin** - Enable ghost mode for invisible online status
- **MK_FuckPaymentsPlugin** - Bypass Telegram payment requirements
- **FakePaymentInterceptorPlugin** - Intercept and fake payment responses
- **UnlockStarsContentPlugin** - Unlock exclusive Telegram Stars content
- **LocalTelegramPremiumPlugin** - Enable local Telegram Premium features

## Usage

All plugins follow the `PluginInterface` and can be loaded via the plugin system.
