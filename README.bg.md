**Мощен Telegram клиент с 105 вградени плагина за подобрена функционалност**

## 🚀 Характеристики

- **105 плагина**: 5 основни плагина + 100 дополнительни плагина
- **Личен домейн**: Достъп до документацията на https://dyrakarmy.eu/
- **Автоматично обновяване**: Вграден систем за обновяване
- **Управление на плагините**: Лесно включване/изключване на конфигурация
- **Преносен режим**: Работи от USB дрив
- **Поддръжка на всички платформи**: Windows, Linux, Android, и iOS

## 🔧 Инсталация

### Windows
1. Теглене на инсталационния пакет от https://dyrakarmy.eu/downloads/
2. Изпълнение на `install_dyrakDGram.bat` като администратор
3. Избор на опция 1 за инсталация
4. След инсталацията, избор на опция 2 за стартиране на приложението

### Linux
1. Изтегляне на пакета:
   ```bash
   wget https://dyrakarmy.eu/downloads/dyrakDGram-linux-1.0.0.tar.gz
   tar -xzf dyrakDGram-linux-1.0.0.tar.gz
   cd dyrakDGram-linux-1.0.0
   ```
2. Инсталация:
   ```bash
   ./install.sh
   ```
3. Стартиране:
   ```bash
   dyrakDGram
   ```

### Android
1. Изтегляне на APK файла от https://dyrakarmy.eu/downloads/dyrakDGram.apk
2. Инсталация на APK файла на вашето устройство
3. Стартиране на приложението

### iOS
1. Изтегляне на IPA файла от https://dyrakarmy.eu/downloads/dyrakDGram.ipa
2. Инсталация през Apple Configurator 2 или sideloading tool
3. Стартиране на приложението
