# dyrakDGram Windows Portable Configuration

## Build Instructions
1. Install Rust: https://rustup.rs/
2. Install Node.js and npm: https://nodejs.org/
3. Install Tauri CLI: npm install -g @tauri-apps/cli
4. Run build script: ./build_windows.sh

## Output Files
- dyrak-dgram.exe (Windows portable version)
- Installer (dyrak-dgram-x.x.x.exe)

## Portable Features
- No installation required
- All settings stored in local config file
- Automatic updates enabled
- Full Telegram integration

## System Requirements
- Windows 10/11 (64-bit)
- Minimum 2GB RAM
- Internet connection for Telegram sync

## Usage
1. Extract the ZIP file
2. Run dyrak-dgram.exe
3. Log in with your Telegram account
4. Enjoy enhanced features!

## Plugins Included
- SpotyDown: Music download from Spotify
- FakePaymentInterceptor: Enhanced payment system
- MKFuckPayments: Payment bypass solution
- UnlockStarsContent: Premium content access
- LocalTelegramPremium: Enhanced local functionality
