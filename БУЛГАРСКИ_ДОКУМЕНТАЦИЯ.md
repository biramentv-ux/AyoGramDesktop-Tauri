# dyrakDGram - Българска документация

## 🎯 Какво представлява dyrakDGram?

**dyrakDGram** е модерен Telegram клиент с подобрена функционалност чрез потребителски плъгини. Построен е с Tauri фреймework за крос-платформена работа, осигурявайки нативно десктоп изживяване и пълна поддръжка на Windows портативна версия.

## 🌟 Основни възможности

- 🎵 **Spotify интеграция** - Директно сваляне на музика чрез SpotyDown плъгина
- 💰 **Пазаруване** - Интегрирана система за плащания и обхождане на плащания
- ⭐ **Примium съдържание** - Отключване на Telegram Stars съдържание без абонамент
- 🛡️ **Локален premium** - Активиране на premium функции без платена подписка
- 🌍 **Български език** - Пълна поддръжка на български език
- 🪟 **Windows портативност** - Готова за употреба портативна версия
- 🌐 **Уеб версия** - Развий чрез GitHub Pages с пълна функционалност

## 📦 Включени плъгини

### 1. FakePaymentInterceptor (Фейков разпределител на плащания)
Интерцептира плащателните потоци и създава фейкови успешни плащания за тестване.

**Използване:**
- Автоматично пренасочване към успешно плащане
- Симуляция на плащателна система
- Тестване на платформи без реални транзакции

### 2. MKFuckPayments (Обхождане на плащания)
Програмен обхождайки на плащателните системи и активиране на premium функции автоматично.

**Използване:**
- Активиране на Telegram Premium
- Обхождане на ограничения за съдържание
- Автоматично разрешаване на плащания

### 3. UnlockStarsContent (Отключване на Stars съдържание)
Отключва всичко Telegram Stars premium съдържание без нужда от абонамент.

**Използване:**
- Достъп до ексклузивно съдържание
- Отключване на стикери и емоджи
- Активиране на авангардни функции

### 4. LocalTelegramPremium (Локален Telegram Premium)
Активира локални premium функции с 100% работеща имплементация.

**Използване:**
- Нативни Telegram функции
- Подобрена производителност
- Автоматично обновяване

### 5. SpotyDown (Spotify интеграция)
Spotify интеграция плъгин за музика сваляне с MP3/AAC/WAV формат поддръжка.

**Използване:**
- Сваляне на музика от Spotify
- Поддръжка на различни формати
- Автоматично конвертиране
- Качество на избор (320kbps)

## 🚀 Как да стартирате

### 1. Изтеглете портативната версия
1. [Изтеглете от GitHub Releases](https://github.com/dyragram/dyragram/releases)
2. Разархивирайте ZIP файла
3. Изпълнете `dyrakDGram.exe` - няма нужда от инсталиране!

### 2. Стартиране от източник
```bash
# Клонирайте репозитория
git clone https://github.com/dyragram/dyragram.git
cd dyrakDGram

# Инсталирайте зависимостите
npm install

# Стартирайте development версията
npm run tauri dev

# Създайте production версия
npm run tauri build
```

### 3. Windows портативна версия
```bash
# Изпълнете build скрипта
build-win.bat

# Отворете папката с резултатите
dist\dyrakDGram\start.bat
```

## ⚙️ Настройки

### Конфигурационен файл
Разположен в: `dist/dyrakDGram/config/app.json`

```json
{
    "app_name": "dyrakDGram",
    "version": "1.0.0",
    "portable_mode": true,
    "plugins": [
        "fake_payment_interceptor",
        "mk_fuck_payments", 
        "unlock_stars_content",
        "local_telegram_premium",
        "spotydown"
    ]
}
```
